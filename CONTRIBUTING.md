# Contributing

**We are not accepting external contributions yet.**

helm is published pre-1.0 as an honest breadcrumb for others building agent fleets — the harness, doctrine,
and file layout are still moving, and the project isn't set up to review outside changes at this stage.

You're very welcome to:
- **read it** — `DOCTRINE.md` and `ARCHITECTURE.md` are the point;
- **fork it** — it's Apache-2.0 (see `LICENSE`); adapt it to your own fleet;
- **open an issue** to report a problem, ask a question, or share how you're using it.

When we do open up to contributions, a **Developer Certificate of Origin (DCO)** sign-off will be required on
commits (`git commit -s`), and this file will describe the workflow. Until then, please don't send PRs — they
may sit unreviewed.

One house rule that will carry over regardless: **no AI attribution in commit messages or PR bodies** (no
`Co-Authored-By: <assistant>`, no "Generated with …" footers). It's a helm doctrine, not a slight.
